# 가장자리 케이스 (내부 테스트용)

이 파일은 일반 사용자가 읽는 글이 아니라, 렌더가 깨지지 않는지 확인하기 위한 모음입니다.

## 깨진 수식

닫히지 않은 수식은 원문 그대로 남아야 합니다: $x + 1

## 깨진 다이어그램

```mermaid
graph TD
    A[닫히지 않은 화살표 -->
```

위 블록은 오류 표시와 함께 원문이 보여야 합니다.

## 섞인 HTML

문장 중간에 <sub>아래첨자</sub> 같은 표시가 섞여도 문서는 그대로 저장되어야 합니다.
